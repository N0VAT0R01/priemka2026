# КнАГУ AI — версия 2.0

Современный статический прототип для ВКР, работающий на GitHub Pages без backend и API-ключей.

## Возможности

- AI-подобный чат с базой знаний;
- источники ответов;
- поиск направлений по названию/коду;
- фильтр по вступительным предметам;
- каталог программ и мест;
- интерактивная проверка набора предметов;
- демо-панель сотрудника;
- статистика автоматических ответов;
- журнал вопросов без ответа;
- localStorage для сохранения статистики;
- адаптивный интерфейс.

## GitHub Pages

Загрузите `index.html`, `style.css`, `app.js`, `data.js` в репозиторий.
Settings → Pages → Deploy from a branch → main → / (root).

## Важно для ВКР

GitHub Pages не должен содержать секретный ключ LLM. Поэтому эта версия работает без внешнего AI API.

Следующий архитектурный этап:
абитуриент → backend → поиск по актуальным документам КнАГУ (RAG) → LLM → ответ + источник.

Источники:
